# NORD Café Especial — laboratório de diagnóstico

Projeto Astro para atividade de avaliação e otimização web.

## Executar localmente

1. Extraia em uma pasta local 
2. Execute `npm install`. (instalar dependências)
3. Execute `npm run dev`. (executar localmente)
4. Abra `http://localhost:4321/`.

O projeto contém problemas técnicos intencionais para diagnóstico e correção.
